# Site Valville — V1

Primeira versão do novo site institucional do Valville.

## Rodar localmente

```powershell
npm install
npm run test
npm run dev
```

Acesse `http://localhost:3000`.

## Validar build

```powershell
npm run build
```

## Escopo desta versão

- Home institucional premium e responsiva.
- Fotos reais fornecidas para o projeto.
- Portal do Morador apontando para o fluxo CPF existente no App Operações.
- Acesso Restrito para sistemas internos.
- Blocos de infraestrutura, segurança institucional, gestão e tecnologia.
- Prévia de Novidades e Newsletter, ainda sem backoffice.

## Importante

Nenhuma alteração de DNS, HostGator ou App Operações é necessária para testar este pacote.

O logo está referenciado temporariamente pela URL pública já usada no App Operações. Na publicação definitiva, o arquivo do logo será incorporado diretamente a este projeto.
